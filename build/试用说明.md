# 巡检截图小组件 · 试用说明（v1.0.1）

## 1. 怎么运行

把 InspectionWidget.exe（连同同目录的 InspectionWidget.exe.manifest，若有）拷到 Windows 机器任意文件夹，双击 → 弹出管理员确认点「是」→ 右下角出现小面板。

## 2. 第一次要做的事

先弹框选截图保存根目录（只选这一次，以后不再问；选错了在设置 → 存储与通用里改）。

## 3. 怎么截图

点面板上的设备名（按钮变蓝）→ 再点要截的那个程序窗口 → 图自动存到「根目录\今天日期\设备名.png」。点错了按 Esc、点右键或再点一次该设备名取消；窗口被挡住也能截完整。

## 4. 凭据怎么加

点面板右上角设置 → 凭据管理 →「+ 添加凭据」填名称和内容 → 保存。回面板点凭据按钮即复制，粘贴后 30 秒自动清空剪贴板（设置里可关）。

## 5. SmartScreen 提示怎么办

首次运行若弹「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（本程序未做商业签名，属预期现象；若单位策略直接禁止运行，把提示截图发回，不要改系统策略）。

## 6. 试跑重点看这几项

- 管理员窗口：以管理员打开一个终端/管理工具，能正常截到、点击不穿透；
- 遮挡：目标窗口被挡一半，截出的图是否完整、无黑边；
- 缩放：显示缩放 150% 时截图是否清晰不发虚；
- 副屏：窗口拖到副屏截图位置是否正确；
- 重名：同设备连截 3 张，文件名是否为 设备名.png、-1、-2；
- 凭据：复制后等 30 秒剪贴板是否自动清空；打开 config.json 搜凭据原文应搜不到。

## 7. v1.0.1 新增（2026-11-03）

- **设置窗口居中**：点设置后窗口出现在屏幕中央，不再贴右下角。
- **界面缩放（4K 屏看这里）**：设置 → 存储与通用 →「界面缩放」，可选 100%/125%/150%/175%/200%。4K 屏建议 150% 或 200%。保存后面板立刻变大/变小；设置窗口本身下次打开按新档位显示。
- **配置存放位置变了**：配置默认存到 `%LocalAppData%\InspectionWidget\config.json`，exe 所在文件夹不再多出 config.json（若 exe 旁已有 config.json，仍优先读它）。设置 → 存储与通用里能看到当前实际生效的配置文件路径。
