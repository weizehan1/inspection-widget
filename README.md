# inspection-widget

巡检截图小组件：Windows 零依赖桌面小工具（C# WinForms + .NET Framework，单文件 exe）。

- 点集群名 → 点目标窗口 → 只截该窗口，自动归档到 `根目录\日期\集群名.png`
- 10 个凭据按钮：DPAPI 加密存储，点一下复制到剪贴板
- 右下角置顶小窗、默认管理员启动、配置存程序同目录
