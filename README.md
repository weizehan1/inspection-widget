# inspection-widget

巡检截图小组件的设计仓库。计划使用 C# WinForms + .NET Framework 4.8，交付单文件 exe。

**当前状态：只有设计文档，尚无源码、工程、测试或可运行 exe。** 本轮为文档审计修订，不代表功能已实现。

- 计划交互：点集群名 → 点目标窗口 → 只截该窗口，归档到 `根目录\日期\集群名.png`，重名顺延且不覆盖。
- 10 个凭据位：DPAPI 当前用户范围加密，点击复制；凭据区可折叠并记忆状态。
- 右下角置顶、最小化进任务栏、默认管理员启动；根目录首次选定后记住。
- 配置优先存程序同目录，不可写时回退用户本地应用数据目录；实际路径在设置中展示。

“零依赖”指目标机已有 .NET Framework 4.8+ 时不另装运行时，不表示兼容所有 Windows 版本。开发计划使用 VS 2022 / MSBuild 和 4.8 目标包；当前尚无构建或运行命令，工程入库后补齐。开发机、实测机与界面定版节奏仍待落实。
