# v1.1.0 设计契约（暖石板 + 深海青紧凑 HUD）

用户于 2026-11-14 选定方案 B，并于 2026-11-15 确认 **暖石板 + 深海青终端风紧凑 HUD** 全量视觉与文案收敛。正式设计依据见同目录 `DESIGN.md`；本文保留共用视觉令牌与状态映射。

## 共用视觉

- 字体：`Segoe UI` 优先，中文回退 `Microsoft YaHei UI`；计划主计数使用系统等宽字体（`Cascadia Mono > Consolas > Menlo > Courier New`）18px Bold。标题 15px Bold，分区标题 12px Bold，设备名 13px，正文 12px，辅助与状态 11px。
- 颜色：暖石画布 `#F6F5F1`，纯白卡片 `#FFFFFF`，凹陷暖石底 `#EDEBE4`，进度条轨道 `#DFDCD2`；主文字 `#1F2421`，次文字 `#575B58`，弱文本 `#767A75`，边框 `#DCD9D0`，柔边 `#E7E4DC`；深石青主操作 `#0F5C6E`（浅底 `#E6F1F3`、边 `#B6D3DA`），琥珀等待态 `#B45309`（浅底 `#FEF3E2`），成功 `#1B6B4A`（浅底 `#E8F4EE`），错误 `#B42318`（浅底 `#FEF0EE`）。
- 间距：主面板左右留白 14px，分区间距 10px；标题区 56px，快捷链接与凭据行高 30px / 间距 6px，设备行高 40px / 间距 6px，底部操作区 96px；计划卡内含 3px 左侧强调条、18px 等宽计数与 6px 圆角胶囊进度条。
- 图标与文案：统一 GDI+ 细线矢量风格，不依赖 Emoji/图标字体，不使用尾随 `↗`、冗余 `✓` 文字前缀或中点 `·` 拼接。所有图标按钮有辅助名称和悬停提示。

## 状态映射

| 业务事实 | 界面表达 |
| --- | --- |
| 点击已被状态机接受 | 左侧圆标呈绿色对勾，右侧状态写“已点过”（无 `✓` 前缀），计数加一 |
| 重复点击 | 再进截图流程；不取消状态标、不重复累计 |
| 等待选窗 | 窗体 2px 与当前设备行均呈琥珀色 `#B45309`（含 3px 左侧条、浅琥珀底），状态写“等待选窗”；标题区提示点击目标窗口 |
| 截图中 / 保存中 | 窗体与当前行呈深石青 `#0F5C6E`（含 3px 左侧条），行内写“截图中”/“保存中”；忙碌时禁用新的截图提交 |
| 抓图/保存失败 | 已有状态标保留；行内或底部显示具体原因与“点击此处重试”入口，不以纯变红替代文案 |
| 全部点过 | 计划卡左侧提示“已点过”、右侧等宽大号显示 `X / X`；全隐藏时显示“本轮已全部点过”；链路结束后询问一次 |
| 计划关闭 | 隐藏计数、进度条与重置入口；左侧强调条置灰 `#DCD9D0`，同日进度保留，设备截图仍可操作 |
| 空名单 | 显示“尚未配置截图设备”与“去设置添加”入口；不计完成、不弹询问 |
| 写保护 | 禁用截图保存，底部与路径区提示原配置已保留及“重试读取配置”入口 |
| 凭据 | 独立矢量复制图标与名称；复制倒计时显示“已复制，X 秒后清空”；不显示秘文内容 |
| 文件夹 | 固定“打开巡检文件夹”动作（配矢量右指箭头），路径独立省略；使用本轮实际保存/暂存目录 |

重置本轮需经过红色危险确认弹窗；单项恢复未点不清除文件。完成询问的“稍后”阻止本轮重复弹出。

## 已选结构

- 主面板：352px；链接 → 计划 → 凭据 → 设备，底部深石青主操作文件夹按钮。
- 设置、导入预览与内置弹窗：统一暖石板底 + 纯白分组卡（替代 `GroupBox`）、`DeviceEditorControl` 复用 `UiTheme.GridStyle`、内置弹窗统一卡片 + 左侧强调条 + 底部白底按钮栏。
