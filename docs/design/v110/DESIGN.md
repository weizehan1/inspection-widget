# 巡检助手 v1.1.0 正式界面设计

日期：2026-11-14。用户已选定 **方案 B「入口与清单」**；本文件作为 WinForms 实现与视觉复核依据。

## 结构与尺寸

- 主面板默认 352 × 660 逻辑像素；高度随内容与当前工作区调整，不把 660 当固定最小高。
- 标题和完整日期之后，内容顺序为：快捷链接 → 巡检计划 → 凭据 → 截图设备。
- 链接与凭据是前面的常用工具区；计划紧邻设备清单，便于同时查看进度与待点项目。
- 中间内容区滚动；标题、日期和底部状态/文件夹入口固定。默认三设备、两凭据完整显示，长名单才滚动。
- 底部使用主色“打开巡检文件夹”按钮，路径独立一行省略展示并保留完整提示。

## 视觉与控件

- `Segoe UI` 优先，中文回退 `Microsoft YaHei UI`。标题 15px，分区标题 12px，设备名 13px，正文 12px，辅助状态 11px。
- 主文字 `#202A35`，次文字 `#5B6875`，边界 `#D5DDE5`，页面 `#FFFFFF`，分区 `#F4F7FA`，主操作 `#2463A0`。
- 左右留白 14–16px；设备行最小高 44px、间距 7px；分区保持紧凑但不压缩点击区域。
- 链接为两列按钮；凭据为两列、带复制图标的独立操作；设备为单列，圆形状态标记与设备名、状态文字同行。
- 设备行描边、状态形状和文字共同表达状态，不只依靠颜色。所有图标按钮提供辅助名称、悬停提示和键盘焦点。

## 状态与行为

- 对勾仅表示点击已被截图状态机接受，不表示截图或保存成功；重复截图不取消对勾、不重复计数。
- 等待选窗、截图中、保存中、失败、暂存和保存成功分别使用明确文字；忙碌时阻止新的截图提交。
- 全勾只写“已点过 X / X”。选窗、截图、保存链路结束后才进行一次完成询问，不抢选窗焦点。
- 单项恢复未点不删除文件；重置本轮需要确认。计划关闭时隐藏计数，同日进度保留。
- 2026-11-14 用户追加：设置“已点过设备的显示方式”，可选“隐藏已点过（适合多设备）”或“保留并显示对勾（适合少设备）”；默认隐藏，仅计划模式启用时生效。点击被接受后即隐藏该行，当前选窗/截图/保存上下文不丢失，状态区继续显示设备与结果。
- 隐藏只过滤展示，不删除设备配置或进度记录，计数和全勾判定始终使用完整计划；提供“查看已点过/只看未点过”临时显示切换以便补截和单项恢复。全部隐藏时显示“本轮已全部点过”，不显示“尚未配置设备”；恢复未点、重置或新一天按规则重现。
- 写保护时暂停保存并保留重试读取入口；文件夹入口与完成询问共用实际保存/暂存目录解析。
- 保留右下角锚定、工作区钳制、滚动、折叠、托盘和截图时隐藏行为。

## 设置窗口

默认 760 × 590，按工作区钳制。左侧分类为设备、凭据、快捷链接、存储与显示、配置备份；右侧编辑区独立滚动，底部固定应用、保存并关闭、取消。

字段编辑必须保留草稿和焦点，不得因一次输入重建表单或恢复默认值。切换分类后再次返回，未保存名称与地址仍须保留。保留草稿、应用/取消、导入预览、原子写入、冲突与写保护机制。

## 实现与验收

沿用 WinForms / .NET Framework 4.8 和系统控件，使用 `TableLayoutPanel`、滚动宿主及自绘状态标记；不引入 WebView、Electron、图标字体或第三方运行依赖。

预览基线为 `docs/design/v110/preview.html` 中的方案 B。实现后须核对默认尺寸、长名单、大字体、键盘操作及 100%/125%/150%/200% 和混合 DPI；真实 Windows 截图、托盘、选窗、保存与目录打开不能由 HTML 检查代替。
