# 巡检助手 v1.1.0 正式界面设计

日期：2026-11-15（基于 2026-11-14 选定的 **方案 B「入口与清单」**，演进为 **暖石板 + 深海青终端风紧凑 HUD**）。本文件作为 WinForms 实现与视觉复核依据。

## 结构与尺寸

- 主面板默认 352 × 660 逻辑像素；高度随内容与当前工作区调整，不把 660 当固定最小高。
- 标题（56px）含应用标题与独立完整日期；内容区自上而下固定顺序：快捷链接 → 巡检计划 → 凭据 → 截图设备；底部固定反馈、主操作“打开巡检文件夹”与路径省略行（96px）。
- 快捷链接行高 30px / 间距 6px；凭据行高 30px / 间距 6px；设备行高 40px / 间距 6px；标题栏三按钮统一矢量线框绘制。
- 巡检计划卡采用纯白卡片 + 左侧 3px 垂直强调条（启用 `#0F5C6E`、全部点过 `#1B6B4A`、关闭 `#DCD9D0`）+ 左侧“已点过”标签与右侧 18px 粗体等宽计数 `X / X` + 6px 圆角胶囊进度条 + 紧凑操作按钮行（20px 高）。
- 中间内容区独立滚动；默认三设备、两凭据完整显示，长名单才滚动。

## 视觉与控件

- `Segoe UI` 优先，中文回退 `Microsoft YaHei UI`；计划计数采用系统等宽字体栈（`Cascadia Mono > Consolas > Menlo > Courier New`）。标题 15px，分区标题 12px，设备名 13px，正文 12px，辅助状态 11px，计划计数 18px。
- 暖石板 + 深海青终端风色板：暖石画布 `#F6F5F1`，纯白卡片 `#FFFFFF`，凹陷暖石底 `#EDEBE4`，进度条轨道 `#DFDCD2`；主文字 `#1F2421`，次文字 `#575B58`，弱文本 `#767A75`，边框 `#DCD9D0` / 柔边 `#E7E4DC`；深石青主操作 `#0F5C6E`（悬停 `#0B4755`、浅底 `#E6F1F3`），琥珀等待态 `#B45309`（浅底 `#FEF3E2`），成功 `#1B6B4A`（浅底 `#E8F4EE`），错误 `#B42318`（浅底 `#FEF0EE`）。
- 快捷链接、凭据按钮与底部“打开巡检文件夹”均去掉尾随 `↗` 字符，改用 GDI+ 矢量外链/箭头/警示图标；主面板与设置、导入窗体均避免模板化中点 `·` 拼接，使用自然中文标点（如“已复制，30 秒后清空”）或独立换行排版。
- 设备行为单列纯白卡片，左侧矢量圆形状态标与设备名、右侧状态文字（“已点过”/“待截图”，无冗余 `✓` 文字前缀）同行；等待态高亮琥珀边框、3px 左侧条与琥珀状态点，截图态高亮深石青边框与 3px 左侧条。

## 状态与行为

- 圆形对勾与“已点过”仅表示点击已被截图状态机接受，不表示截图或保存成功；重复截图不取消状态标、不重复累计。
- 等待选窗（琥珀色 `#B45309`）、截图中（深石青 `#0F5C6E`）、保存中、失败、暂存和保存成功（“已保存：文件名”，无 `✓` 前缀）分别使用明确文字；忙碌时阻止新的截图提交。
- 计划计数由“已点过”与等宽 `X / X` 共同表达。选窗、截图、保存链路结束后才进行一次完成询问，不抢选窗焦点。
- 单项恢复未点不删除文件；重置本轮需经过“确定重置”红色警示确认弹窗。计划关闭时隐藏计数，同日进度保留。
- 设置“已点过设备的显示方式”，可选“隐藏已点过（适合多设备）”或“保留并显示对勾（适合少设备）”；默认隐藏，仅计划模式启用时生效。全部隐藏时展示带 3px 左侧成功条的“本轮已全部点过”提示卡。
- 写保护时暂停保存并保留重试读取入口；文件夹入口与完成询问共用实际保存/暂存目录解析。
- 保留右下角锚定、工作区钳制、滚动、折叠、托盘和截图时隐藏行为。

## 设置窗口、导入预览与内置弹窗

- 设置窗口（`SettingsForm`，“巡检助手设置”）默认 760 × 590，按工作区钳制；去除传统 `GroupBox`，全部采用 `UiTheme.CreateSectionCard` 纯白分组卡与细分割线；设备编辑表格（`DeviceEditorControl`）复用 `UiTheme.GridStyle`；关于页拆行排版，带 3px 深石青左侧强调条。
- 导入预览窗口（`ConfigTransferForm`）同样去除 `GroupBox`，统一纯白分组卡与底部白底操作栏。
- 主面板与设置内置弹窗（`ProgressRecoveryDialog`、`ResetRoundConfirmDialog`、`CompletionPromptDialog`、`DiscardChangesDialog`、`ExportChoiceDialog`）统一暖石板底 + 纯白内容卡（含 3px 左侧强调条）与细边底部按钮栏，高危确认动作使用 `DangerButton`。

## 实现与验收

沿用 WinForms / .NET Framework 4.8 和系统控件，使用 `TableLayoutPanel`、滚动宿主及 GDI+ 自绘矢量状态与图标；零第三方运行依赖，保持 C# 7.2 / macOS `xbuild` 兼容。

实现后须核对默认尺寸、长名单、大字体、键盘操作及 100%/125%/150%/200% 和混合 DPI；真实 Windows 截图、托盘、选窗、保存与目录打开须在 Windows 环境实测验证。
