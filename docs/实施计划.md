# 巡检截图小组件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个零依赖、单文件、默认管理员启动的 Windows 巡检截图小组件 `InspectionWidget.exe`（点设备名 → 点窗口 → 只截该窗口存入 `根目录\yyyy-MM-dd\设备名.png`；凭据一键复制、DPAPI 加密、30 秒安全清空）。

**Architecture:** 单 WinForms 工程（.NET Framework 4.8），按职责分 Config / Capture / Storage / Credentials / Native 五个模块；平台无关逻辑（配置校验、布局高度、状态机、命名顺延、清空决策、裁边几何、黑图采样）全部抽成可单测的纯逻辑，Windows 专属能力（钩子、PrintWindow、DPAPI、真实剪贴板）藏在接口后面。本机 Linux 用 Mono 编译与跑纯逻辑测试，Windows 专属部分保证编译通过并逐项标注「待 Windows 验收」。

**Tech Stack:** C# 7.3、WinForms、.NET Framework 4.8；系统程序集仅限 System / System.Core / System.Drawing / System.Windows.Forms / System.Security / System.Runtime.Serialization；序列化用 `DataContractJsonSerializer`，加密用 `ProtectedData`（DPAPI, CurrentUser）；零 NuGet。构建：Windows 用 VS2022/MSBuild，本机用 Mono msbuild（`build.sh`）。

**Spec:** 白皮书 `~/workspace/your_files/inspection-screenshot-whitepaper-md/inspection-screenshot-whitepaper.md`（v0.3 终审合并版，权威第一）；开发步骤 `~/workspace/your_files/inspection-widget-dev-steps/inspection-widget-dev-steps.md`（v0.2，阶段与验收权威）；设计稿 `~/workspace/widget-design/widget-ui-design.svg`（尺寸/颜色/字号令牌权威）。

## Global Constraints

- 目标框架锁定 .NET Framework 4.8，语言版本 C# 7.3 以内；句柄一律 `IntPtr`/`UIntPtr`；关「首选 32 位」，Any CPU。
- 严禁任何第三方 NuGet 包；只许 .NET Framework 系统自带程序集。
- 产品名全板统一「巡检截图小组件」，标题栏短名「巡检截图」；设置四组：设备管理、凭据管理、存储与通用、关于。
- 配置字段名固定：`RootPath`、`Devices`、`Credentials`（条目 `Title` + `EncryptedSecret`）、`IsCredentialCollapsed`（默认 false）、`AutoClearClipboard`（默认 true）、`CaptureMode`（Auto / PrintWindowOnly / BitBltOnly，默认 Auto）、`WindowLeft`、`WindowTop`、`LastDevice`。
- 配置路径必须用 `AppDomain.CurrentDomain.BaseDirectory` 拼 exe 同目录 `config.json`，严禁相对路径；不可写回退 `%LocalAppData%\InspectionWidget\config.json`；已有回退配置优先读；一次只写一个权威位置。
- 配置写入：同目录唯一临时文件 + `File.Copy(tmp, target, overwrite:true)` + 删 tmp（禁对已存在文件 `File.Move`）；以权威路径为粒度用锁文件（`FileShare.None` 长持）跨会话互斥，拿不到锁不写入。
- 凭据上限 10 条、下限 0 条，按实际条目数渲染，无空槽无置灰占位；0 条时凭据区只显示分区标题 + 「未设置凭据，去设置添加」提示行。
- 面板布局令牌（设计稿，96 DPI 逻辑像素）：面板宽 230；标题栏 36；分区标题行 28；底部状态区 58（反馈行 + 根目录行）；设备行高 33、行距 5；凭据行高 33、行距 8；空态提示行高 33。总高 = 36 + 28 + 设备区 + 28 + 凭据区（折叠时 0） + 58；设备区 = n×33 + (n−1)×5（n=0 时 33）；凭据区 = n×33 + (n−1)×8（n=0 时 33）。
- 高度变化一律以窗口 Bottom 为锚点反算 Top 并按 `Screen.WorkingArea` 钳制顶沿，严禁默认左上锚点伸缩。
- 颜色令牌：强调 #0067C0、成功 #0F7B0F、错误 #C42B1C、主文本 #1B1B1B、次文本 #424242、弱文本 #616161、面板底 #F9F9F9、边框 #E0E0E0；字体 Segoe UI / 微软雅黑，字号（px 单位）11 / 13 / 16 / 20；圆角：面板 10、控件 6、徽标 4（WinForms 实现以近似为准，属已知偏差）。
- 钩子：只在待截图状态挂载；钩子运行在独立消息循环线程；回调只记坐标并返回，重活（反查、截图、写盘）在工作线程，UI 线程只收状态与提示更新；外部点击成对吞 `WM_LBUTTONDOWN` + `WM_LBUTTONUP`；点在组件自身矩形内放行；右键 / 全局 Esc 取消；30 秒超时自动取消；钩子委托必须强引用防 GC。
- 截图：`PrintWindow` 必须带 `PW_RENDERFULLCONTENT (0x00000002)`，按 `GetWindowRect` 完整矩形抓、按 `DWMWA_EXTENDED_FRAME_BOUNDS` 偏移内存裁边，严禁直接按 DWM 尺寸建位图；黑图判定 = 15×15 网格采样、纯黑或全透明占比 > 98%（只判「可疑」）；回退 BitBlt 按 DWM 边界抓、置前须核查结果、与组件重叠时组件 `Opacity=0` 等约 60ms 再抓；回退仍黑 → 提示不落盘。`PrintWindow` 同步阻塞须离开 UI/钩子线程，超时只失效请求、未返回前禁再启、其 DC/位图独占至返回后释放。
- 保存：`根目录\yyyy-MM-dd\设备名.png`，同名顺延 `-1`、`-2` 取最小未占用序号，用 `FileMode.CreateNew` 原子创建，仅重名冲突顺延（有界重试），成功关闭后才报告成功，失败只清理本次不完整文件；日期在采集开始时固定；根目录不可写时两级暂存 `FallbackScreenshots\yyyy-MM-dd\`（exe 同目录 → `%LocalAppData%\InspectionWidget\`），两处均失败保留内存图供重试并提示「尚未保存」。
- 剪贴板：写入在同一次 `OpenClipboard` 锁内完成并记录 `GetClipboardSequenceNumber` + 本次令牌（自定义格式写入 GUID）+ SHA256 辅助；写入时设置禁止历史/云同步格式；30 秒到期在同锁内核对序列号与令牌一致才 `EmptyClipboard`，无法核对则跳过并提示；每次复制重置定时器；`FormClosing` 时未到期且匹配先清再退；写入失败间隔 50ms 重试 3 次。
- 设备名校验（保存与加载统一）：拦截非法字符 `\ / : * ? " < > |`、控制字符、空名、`.`/`..`、尾部空格或点、Windows 设备保留名（含带扩展名形式，如 `CON.txt`），按大小写不敏感查重；校验追加序号后的完整路径长度（< 260）。
- 损坏自愈分类：缺失=首次初始化（不备份）；缺可选字段=只补默认；语法/结构损坏=先备份为 `config.corrupt.时间戳.json`（备份失败不覆盖原件）再载默认；读取 I/O 失败=提示并保留文件不重置；单条密文解不开=仅该条标「需重新设置」。
- 全局异常写 exe 同目录 `error.log`（不可写回退 LocalAppData），绝不记凭据明文与截图内容。
- 单实例 Mutex 防多开；manifest `requireAdministrator` + PerMonitorV2 DPI；`Program.cs` 入口加 DPI API 兜底声明。
- 本次执行特别约束（用户 2026-11-02 指示）：**不推送 GitHub、不加 remote**；阶段 9 只做本地收口（README、本地标签 `v1.0.0`、产物哈希记录），远程核对延期并在报告中注明。
