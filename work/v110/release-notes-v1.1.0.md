## 巡检助手 v1.1.0（Windows 10/11 · .NET Framework 4.8）

### 主要更新

- **主面板方案 B 改版（352px 紧凑浮动面板）**
  - 顶栏显示「巡检助手」与独立中文完整日期行；
  - 顶部新增 **2 列快捷链接宫格**（最多 12 条 `http://` / `https://` 网址，支持单条启用/停用与系统默认浏览器打开）；
  - 新增 **今日巡检计划进度卡片**（按自然日跟踪「已点过 X / Y」、开关切换、查看已点过、单行恢复未点、二次确认重置、全部点完后按面板可见态触发一次完成提示）；
  - **2 列凭据高亮与已复制标记**；
  - 底部主操作按钮「**打开巡检文件夹 ↗**」，当日存在暂存目录等多个实存目录时弹出菜单选择直达。
- **今日进度与数据健壮性**
  - 新增 `HideVisitedDevices`（默认开启点完即隐藏）；配置改名与仅含局部字段的非合并导入不再误清当日已点进度；
  - 进度独立持久化至 `%LocalAppData%\InspectionWidget\progress.json`，区分「有效昨日进度」与「损坏/同日坏快照」：`progress.json` 损坏时进入只读保护并保留坏原件，支持主面板「恢复进度」重试读取或先备份再重置新轮；跨午夜忙碌期间保留待刷新标记，回归空闲后自动重建新日列表。
- **五页设置窗口与界面交互修复**
  - 设置窗口重组为「设备 / 凭据 / 快捷链接 / 存储与显示 / 配置备份（含关于）」五页，新增支持中文/高 DPI 缩放（100%–200%）与缩放重建旧字体安全延后释放；
  - 修复主面板与设置列表 `AutoScroll` 滚动偏移位置漂移、`Waiting` 态面板高度变动同步选窗钩子区域、`Waiting` 态重复点击当前设备取消选窗等边界问题。
- **全新应用图标**
  - 采用重新生成的深青蓝底白色取景框应用图标，exe / 窗口 / 托盘图标同源。

### 运行与交付说明

- 由 GitHub Actions（`windows-latest`）使用 VS2022 MSBuild 构建为单文件 `InspectionWidget.exe`（已内嵌 `requireAdministrator` 管理员权限与 `PerMonitorV2` 高 DPI 声明）；
- 首次运行如出现 Windows SmartScreen 提示，可点「更多信息」→「仍要运行」（未购买商业代码签名）；
- 配置默认存 `%LocalAppData%\InspectionWidget\config.json`（若 exe 同目录存在 `config.json` 则优先便携使用）。
