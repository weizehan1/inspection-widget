## v1.2.1 — 右键成对取消、未点计数守恒与选窗体验优化

### 主要更新
- **右键取消成对拦截**：在 `HookManager` 中成对拦截 `WM_RBUTTONDOWN` 与 `WM_RBUTTONUP`（卸载时同样等待配对抬起或 200ms 安全窗口），彻底避免右键取消选窗时在目标窗口或桌面弹出右键菜单，并过滤卸载期迟到取消事件。
- **取消不改变今日巡检未点设备条数**：将 `InspectionSessionController` 的 `MarkVisited` 从“点下设备进入等待选窗”延后到“真正截图并保存成功后”，等待选窗期间设备行保持可见并展示琥珀色「等待选窗」高亮；右键、Esc、再点一次、超时取消或抓图失败均不减少今日未点设备数，也不会误触发完成弹窗。
- **选窗悬停目标窗口高亮框**：新增 `TargetHighlightOverlay` 镂空置顶高亮框（不拦截点击、不抢焦点），选窗期间实时框出鼠标悬停的有效目标窗口外框，退出等待或开始抓图前立即隐藏。
- **主面板效率与性能细节**：设备区标题直接显示今日 `待点 N 台` / `今日已全点`；空闲态设备行支持右键快捷菜单（截取 / 恢复未点 / 打开今日巡检目录）与 `↑` / `↓` 方向键切换焦点；分离设备行独立 `ToolTip` 并在名单未变时复用既有行控件以消除闪烁与句柄累积。
- **自动化测试扩展**：逻辑与集成测试扩展至 **454 条**，Windows UI 测试扩展至 **29 条**（共 **483 条**）。
