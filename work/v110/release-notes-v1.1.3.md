## v1.1.3 — Windows 实机设置界面布局与 DPI 适配修复

### 主要更新
- **设置窗与导入预览窗底栏及响应式布局**：修复高 DPI 缩放下 `TableLayoutPanel` 行列样式与外边距异常导致的“应用 / 保存并关闭 / 取消”按钮被挤出右下角问题，启用最大化按钮并按工作区动态约束初始窗口尺寸与最小尺寸。
- **快捷链接与凭据列表排版重整**：恢复表头显示与严格对齐列宽，动态新增行同步按当前界面缩放系数缩放高度，消除行内控件纵向裁切，并新增原生输入框占位提示（Cue Banner）、停用行变灰、删除警示红与完整网址 Tooltip。
- **垂直滚动与控件防塌陷**：自页面客户区宽度向下统一约束卡片与内嵌容器最大宽度并预留垂直滚动条宽度，修复“存储与显示”界面缩放下拉框塌陷至 2px 与内容超出时不出现上下滚动条的问题。
- **长文本与长路径自动换行**：修复“存储与显示”“配置备份”等页面的复选框、单选框、说明文案与长路径横向溢出而不自动换行的问题。
- **回归测试扩展**：Windows 窗体 UI 回归用例新增 4 条（共 **443 条纯逻辑/集成 + 27 条 Windows UI = 470 条**），覆盖多缩放底栏可见性、快捷链接/凭据动态行缩放裁切、存储页垂直滚动/缩放框宽度与长文本换行。
